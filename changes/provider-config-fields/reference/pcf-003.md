## 2. Current AddProviderDialog.tsx Form Structure

File: `D:\project-code\llm\openpowers\src\client\components\AddProviderDialog.tsx`

### Component Signature
- `export function AddProviderDialog({ isOpen, onClose, onSuccess }: AddProviderDialogProps)`
- Props: `isOpen: boolean`, `onClose: () => void`, `onSuccess: () => void`

### FormValues Interface (current)
```ts
interface FormValues {
  name: string;
  notes: string;
  websiteUrl: string;
  apiKey: string;
  baseUrl: string;
}
```
- Currently has **5 fields**. No model fields are present.

### Preset Selection Logic

The `handlePresetSelect` function (lines 111-124):
```ts
const handlePresetSelect = (preset: ProviderPreset) => {
  setSelectedPreset(preset.name);
  if (preset.name === '自定义配置') {
    setForm(EMPTY_FORM);
  } else {
    setForm((prev) => ({
      ...prev,
      name: preset.name,
      baseUrl: preset.baseUrl,
      websiteUrl: preset.websiteUrl || prev.websiteUrl,
    }));
  }
  setErrors({});
};
```
- Maps preset fields: `name`, `baseUrl`, `websiteUrl`
- Does NOT currently pass model fields (`ANTHROPIC_MODEL`, `DEFAULT_SONNET_MODEL`, `DEFAULT_OPUS_MODEL`, `DEFAULT_HAIKU_MODEL`) to the form.

### Form Field Layout (add dialog only)
The dialog renders these fields in order:
1. Preset selector grid (4-column grid, scrollable, max-h-40)
2. Name (text input, required)
3. Notes (text input, optional)
4. Website URL (url input, optional)
5. API Key (password/text toggle, required, with eye icon)
6. Base URL (url input, optional)

### Submit Payload (current)
```ts
body: JSON.stringify({
  name: form.name.trim(),
  apiKey: form.apiKey.trim(),
  notes: form.notes.trim() || undefined,
  websiteUrl: form.websiteUrl.trim() || undefined,
  baseUrl: form.baseUrl.trim() || undefined,
})
```
- POST to `/openpowers/api/providers`
- Does NOT include model fields.

### Dialog Styling
- Width: `max-w-3xl` (for add dialog, to accommodate preset grid)
- Styled with `React.createElement` (no JSX)
- Input class: `w-full rounded-lg border border-input bg-background px-3 py-2 text-sm ...`
